# Holiday Destination Website

유럽 여행지 탐색 웹사이트입니다. 친구와 공유할 수 있는 간단하고 아름다운 인터페이스를 제공합니다.

## 기능

1. **Map View**: 지도에서 도시 위치를 확인하고 클릭하면 해당 도시의 이미지를 볼 수 있습니다.
2. **List View**: 도시 목록을 국가별로 확인하고, 비행 시간, 운전 시간, 월별 평균 기온을 확인할 수 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. Map View 또는 List View를 선택합니다.
3. Map View에서는 지도 위의 마커를 클릭하여 도시 이미지를 확인합니다.
4. List View에서는 슬라이드바를 조작하여 월별 평균 기온을 확인합니다.

## 파일 구조

```
Holiday destination/
├── index.html          # 메인 페이지
├── map.html            # 지도 뷰 페이지
├── list.html           # 리스트 뷰 페이지
├── styles.css          # 공통 스타일
├── map.js              # 지도 관련 JavaScript
├── list.js             # 리스트 관련 JavaScript
├── data/
│   └── cities.json     # 도시 데이터
└── README.md           # 이 파일
```

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- JavaScript (Vanilla JS)
- Leaflet.js (지도 라이브러리)
- Unsplash (이미지 소스)
